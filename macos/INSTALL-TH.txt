RightType สำหรับ Mac — พิมพ์ผิดภาษา แก้ให้เอง
=============================================

แอปแก้ข้อความที่พิมพ์ผิดคีย์บอร์ด ไทย ↔ อังกฤษ
(เช่น l;ylfu → สวัสดี, ้ำสสน → hello)

ต้องใช้: macOS 13 ขึ้นไป (Apple Silicon หรือ Intel)

ติดตั้ง
-------
1. ลาก RightType.app ไปไว้ในโฟลเดอร์ Applications
2. คลิกขวาที่แอป → เลือก Open → กด Open อีกครั้ง
   (ต้องทำครั้งแรกครั้งเดียว เพราะแอปยังไม่ได้ลงลายเซ็นจาก Apple
    ถ้าไม่มีปุ่ม Open ให้ไป System Settings → Privacy & Security
    เลื่อนลงแล้วกด "Open Anyway")
3. เมื่อ macOS ถามสิทธิ์ ให้เปิดสวิตช์ RightType ที่
   System Settings → Privacy & Security → Accessibility
   (และ Input Monitoring ถ้ามีถาม)
4. จะเห็นไอคอน "Aก" บนเมนูบาร์ด้านบน เป็นอันเสร็จ
   แอปจะเปิดเองทุกครั้งที่เปิดเครื่อง (ปิดได้ที่เมนู Aก)

วิธีใช้
-------
- ⇧⌫ (Shift + Backspace)  แก้คำล่าสุด กดซ้ำเพื่อย้อนกลับ
- ⌃⌥Space                 แก้ข้อความที่เลือกไว้
- เมนู Aก เลือกโหมดได้:
    Manual   แก้เมื่อกด ⇧⌫ เท่านั้น
    Suggest  มีป้ายเตือน กด Tab เพื่อแก้ (ค่าเริ่มต้น)
    Auto     แก้ให้เองทันที
- แก้คำไทยสะกดผิดที่พบบ่อย: ขึ้นป้าย กด Tab เพื่อแก้

ความเป็นส่วนตัว
---------------
แอปไม่มีโค้ดเชื่อมต่ออินเทอร์เน็ต และไม่เก็บหรือส่งข้อความที่คุณพิมพ์ไปไหน
ที่ต้องขอสิทธิ์ Accessibility เพราะต้องอ่านคีย์ที่กดเพื่อตรวจว่าพิมพ์ผิดภาษา
